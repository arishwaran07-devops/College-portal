# AJV CollegeConnect — AJV College of Engineering

A polished full-stack college portal built for the **Containerizing College Portal Using Docker and DevOps** project.

## Main academic workflow

1. Student fills the mandatory registration form.
2. Backend automatically creates a unique **Login ID / Register ID** such as `AJVSTU004`.
3. The registration success screen displays the Login ID.
4. Student logs in with the generated Login ID and their chosen password.
5. Authorized staff logs in and opens the **Student Directory**.
6. Staff selects a registered student and enters:
   - Attendance percentage
   - Internal mark / 40
   - External mark / 60
7. Backend automatically calculates:
   - Total mark / 100
   - Subject percentage
   - Grade
   - Grade point
   - Overall percentage across recorded subjects
   - Credit-weighted CGPA
   - Average attendance
8. Student can immediately see the updated academic records after logging in again / refreshing.

## Grade calculation

| Total | Grade | Grade Point |
|---:|:---:|---:|
| 90–100 | O | 10 |
| 80–89 | A+ | 9 |
| 70–79 | A | 8 |
| 60–69 | B+ | 7 |
| 50–59 | B | 6 |
| 40–49 | C | 5 |
| Below 40 | RA | 0 |

CGPA is calculated as a **credit-weighted grade-point average**.

## Run in VS Code

Open the project root — the folder containing `package.json` — in VS Code Terminal:

```bash
npm install
npm start
```

Open:

`http://localhost:5000`

The backend automatically creates `data/db.json` on first start. No MySQL installation is required.

## Docker

```bash
docker compose up --build
```

Open `http://localhost:5000`.

The `data` folder is mounted to a Docker volume so the local JSON database persists across container restarts.

## Important

- The supplied college logo image is included as `frontend/assets/college-logo.png` and is displayed without editing; the UI only uses a circular presentation frame.
- Student Login IDs are generated by the backend. Students no longer type their own registration number.
- Staff controls mark entry; students cannot call staff mark APIs because the backend enforces JWT role checks.
- Passwords are stored as bcrypt hashes, not plain text.


## Install as a mobile app (PWA)

This project is configured as a Progressive Web App (PWA).

After deploying to Render over HTTPS:
1. Open the website in Chrome on Android.
2. Use the **Install App** button when it appears, or Chrome menu → **Install app / Add to Home screen**.
3. The AJV shield-and-laurel logo is used as the app icon.
4. The installed app opens in standalone mode and continues to use the same Render backend.

PWA files:
- `frontend/manifest.json`
- `frontend/sw.js`
- `frontend/assets/pwa.js`
- `frontend/icons/icon-192.png`
- `frontend/icons/icon-512.png`
